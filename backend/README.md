# Backend

> **Note:** The comprehensive documentation for this monorepo, including architecture, testing strategies, instructions to run both services, and backend specifics, is available in the [root README](../README.md).

## Quick Start

```bash
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --reload
```

API will run on `http://127.0.0.1:8000`.
